# Sorting Algorithms (C++)

Небольшая учебная работа по алгоритмам сортировки на C++.

В программе алгоритмы оформлены в виде отдельных классов. Для сортировки можно передать компаратор, который задаёт порядок элементов.

## Реализованные алгоритмы

- сортировка подсчётом;
- сортировка вставками;
- сортировка выбором;
- сортировка методом Шелла.

## Как устроена программа

В основе программы лежит шаблонный абстрактный класс `sorting_algorithms<T>`. В нём объявлен виртуальный метод `sort()`, который реализуется в классах отдельных алгоритмов.

Для вывода отсортированного вектора используется метод `print()`. В функции `main()` приведён пример сортировки вектора методом Шелла.

## Сборка и запуск

Для компиляции понадобится компилятор C++:

```bash
g++ -std=c++11 sorting_vector.cpp -o sorting_demo
```

Запуск в Linux и macOS:

```bash
./sorting_demo
```

В Windows:

```powershell
.\sorting_demo.exe
```

## Используемые технологии

- C++
- STL (`std::vector`, `std::function`)
- Шаблоны классов
- Наследование и виртуальные функции
