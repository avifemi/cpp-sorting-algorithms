# Sorting Algorithms — C++

Учебный проект по алгоритмам сортировки на C++.

В работе рассматривается общий интерфейс алгоритмов сортировки и передача компаратора, задающего порядок элементов. Реализации оформлены в виде отдельных классов, наследующих абстрактный базовый класс.

## Реализовано

В текущей версии файла `sorting_vector.cpp` присутствуют:

- сортировка вставками;
- сортировка выбором;
- сортировка методом Шелла;
- алгоритм, названный в коде `sorting_by_counting`.

**Примечание:** последняя реализация распределяет элементы по позициям, вычисленным попарным сравнением. Это ранговая сортировка, а не классическая сортировка подсчётом частот. Название класса пока сохранено таким, каким оно было в исходной лабораторной работе.

## Архитектура

- `sorting_algorithms<T>` — абстрактный базовый класс с виртуальным методом `sort()`;
- классы-наследники — отдельные реализации алгоритмов;
- компаратор — функция, определяющая требуемый порядок элементов.

В исходной версии также есть демонстрационный `main()`, который запускает сортировку методом Шелла.

## Сборка

Для компиляции нужен компилятор с поддержкой C++11 или новее:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic sorting_vector.cpp -o sorting_demo
```

Запуск:

```bash
./sorting_demo
```

В Windows запуск собранного файла обычно выполняется командой:

```powershell
.\sorting_demo.exe
```
